# 日本語の読み比較 — 2026-09-27

漢字・日付・助数詞の読み変換ではQwenに有利な例があった。
ただし、声の明瞭さまで含めた全体の優劣は別で、Qwenにも大きく崩れた出力がある。
**今回の自動認識一致数は、人間が確認した正読率ではない。**

## 実施内容

- 生成前に固定した32文章。文脈8、数字・日付・助数詞12、操作用語8、地名4。
- 私が用意した[読み仮名と許容する別読み](source/readings-ja.json)を使用。TTSには元の文章だけを入力。
- Kokoro 82M `jm_kumo`、Qwen3-TTS 0.6B `Ryan` / `Uncle_Fu`。全員男声。
- 標準速度と1.20の両方。Kokoroは生成時のspeed、Qwenは生成後のffmpeg atempo。
- 4つの対照文章を各声・速度で追加。正しいかな入力2件、意図的な誤読入力2件。
- 全216 WAVを保存。2つの独立したかな認識器で全432件を読み返した。生成・認識実行エラー0。
- CPU、各8スレッド、seed 0。一部ジョブは並行実行。速度ベンチマークには使わない。

## 数値

対象語の読みを音素にして照合した一致数。分母32には不一致や採点不能も含む。
長音表記（ぎょう/ぎょー）と無声化の差は許容し、欠けた母音や子音は残した。
漢字への自動変換や、漢字から推測した読みの再変換は行っていない。

|声|速度|slplab一致数|sakasegawa一致数|sakasegawa 全文かなCER|
|---|---:|---:|---:|---:|
|Kokoro Kumo|1.00|17/32|16/32|15.62%|
|Kokoro Kumo|1.20|4/32|8/32|22.74%|
|Qwen Ryan|1.00|12/32|14/32|30.33%|
|Qwen Ryan|1.20|12/32|15/32|27.87%|
|Qwen Uncle Fu|1.00|8/32|15/32|18.78%|
|Qwen Uncle Fu|1.20|11/32|15/32|20.17%|

1.20では両採点器ともQwenの対象語一致数が上だった。一方、標準速度の全文かなCERはKokoroが最小だった。
したがって「Qwenはすべての日本語発声で高精度」と結論付けない。
声は各モデルの一部だけで、Qwenの男声は日本語ネイティブのプリセットではない。

slplabは名称にhiraganaを含むが、語彙に数字も含まれていた。数字が出た箇所は読みを推測せず採点不能として保持。
そのためslplabの全文CERは、採点不能がある構成ではnull。該当数もJSONに記録した。
すべての合成・認識処理は実行できたことと、すべてを有効に採点できたことを区別している。

## 採点器自体の検査

1.20での対照4件（正しいかな入力2件、意図的な誤読2件）の結果：

|声|slplab：正しい対象語の検出|sakasegawa：正しい対象語の検出|意図的な誤読の拒否（両者）|
|---|---:|---:|---:|
|Kokoro Kumo|1/2|0/2|2/2|
|Qwen Ryan|1/2|1/2|2/2|
|Qwen Uncle Fu|0/2|1/2|2/2|

正解のかなを入力しただけでは、生成音声が必ず明瞭とは限らない。
上の失敗はTTSの発音・明瞭さとASRの聞き違いを完全には分離できない。
特に短い語や1.20倍で取りこぼしが多く、正読率として数字を使うには不十分。
全文CERにも認識器の誤りや長音表記差が入る。人間の試聴・アクセント・自然さの評価は未実施。

## 確認できた具体例

Kokoroの実際の文字→発音変換（misaki / Cutlet）を別途確認した。
音声を聞き取る採点器を通さなくても、次の変換が起きている。

|入力|用意した読み|Kokoro内部の読み|
|---|---|---|
|四月一日|しがつついたち|ヨンガツツイタチ|
|三本|さんぼん|サンポン|
|九月二十日|くがつはつか|キューガツハツカ|
|午後四時|ごごよじ|ゴゴシジ|
|山手線|やまのてせん|ヤマテセン|

[内部変換の全件](readings-v1-kokoro/frontend.json)。これは発音前の処理の証拠であり、耳での評価ではない。
Qwen Ryanの四月一日・三本・九月二十日・午後四時は、両認識器で期待する対象語の読みが一致した。
一方、山手線はRyanでも「やまてせん」と認識された。

Ryanの「温度は二十三点五度です」は13.6秒の出力になり、2つのかな認識器と追加のWhisper検査でも異なる長い音列になった。
同じ文章のUncle FuはWhisperで「温度は23.5度です」と認識された。
[診断結果](readings-v1-qwen/long-output-diagnostic.json)。この追加検査は主集計には混ぜていない。

文脈問題の「人気のない道」「市場で野菜を買う」は別の意味で別読みも成立し得る。
文脈問題は意図した読みを選べたかのテストとして扱い、不一致すべてを日本語としての誤読とは断定しない。
結果を見て正解を書き換えたり、失敗例を分母から除いたりはしていない。
